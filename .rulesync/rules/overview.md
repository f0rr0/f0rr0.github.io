# Project Guidance

- Follow existing code patterns and naming.
- Use TypeScript and Next.js conventions already present in the codebase.
- Prefer existing package scripts for linting, formatting, and typechecking when needed.
- For blog writing and revision, use `.rulesync/skills/blog-writing/SKILL.md` and `BLOG.md`.
- For SEO, AEO, agent readability, indexing, metadata, or publishing validation, use `.rulesync/skills/site-seo/SKILL.md`. Pair it with blog-writing for article work.
